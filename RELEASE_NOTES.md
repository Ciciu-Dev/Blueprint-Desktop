# BLUEPRINT Desktop 1.0

- BLUEPRINT Launcher V5 passed 8 of 8 user-reported functional tests.
- UI overlap fixed in V3.1; the fix remained stable in V5.
- Launcher favourites persisted across reloads and login.
- Clock, CPU and RAM desklet, wallpaper, bottom panel, prompt and icon theme
  survived a fresh-login test (7 of 7 components).
- Idle system load improved during testing, though no controlled benchmark was performed.

This release represents one tested Linux Mint setup, not verified compatibility
across all Linux distributions or Cinnamon versions.
